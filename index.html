Empezar

Paso a paso

Cómo empezar en 4 pasos

  1. Elige qué quieres crear

    ¿Juegos, páginas web, apps, robots? Lo que más te guste te mantendrá motivado.

  2. Aprende a pensar con lógica

    Antes que cualquier lenguaje, aprende a resolver problemas paso a paso.

  3. Practica un poco cada día

    20 o 30 minutos diarios valen más que una tarde entera una vez al mes.

  4. Haz un proyecto tuyo

    Algo pequeño: una página sobre tu equipo favorito, un juego sencillo, un LED que parpadea.

Si eres menor de edad: avísale a tus papás o a un adulto antes de instalar programas o crear cuentas.

La base de todo

Lo que necesitas entender primero

Estas ideas se usan en todos los lenguajes. Si las entiendes, aprender cualquiera será mucho más fácil.

🧠

Lógica y algoritmos

Un algoritmo son los pasos para resolver un problema, como una receta de cocina.

📦

Variables

Cajas con nombre donde guardas datos: tu edad, tu puntuación, tu nombre.

🔀

Condiciones

"Si pasa esto, haz aquello". Así un programa toma decisiones.

🔁

Ciclos

Repetir una acción muchas veces sin escribirla una por una.

🧩

Funciones

Un grupo de instrucciones con nombre que puedes usar cuando quieras.

🐞

Depurar errores

Equivocarse es normal. Buscar y arreglar errores también es programar.

Tu ruta

¿Con qué lenguaje empiezo?

No hay uno "correcto", pero sí un orden que funciona bien. Avanza al siguiente nivel cuando el anterior ya te resulte cómodo.

  1. Nivel 1

    Scratch

    Muy fácil

    Para: hacer juegos y animaciones.

    Armas el programa uniendo bloques de colores, sin escribir código. Perfecto para aprender la lógica.

    ▶ Curso de Scratch · Wonderly, 41 videosAbrir Scratch
  2. Nivel 2

    HTML y CSS

    Fácil

    Para: crear páginas web y ver los resultados al instante.

    HTML es la estructura de la página y CSS es su diseño. Así empecé yo, con el Bloc de Notas.

    ▶ Curso de HTML y CSS · Soy Dalto

    Es un curso muy largo: míralo por partes.

  3. Nivel 3

    JavaScript

    Medio

    Para: hacer páginas web que reaccionan: botones, juegos, formularios.

    Es el siguiente paso después de HTML y CSS. Funciona directo en tu navegador.

    ▶ Curso de JavaScript · freeCodeCamp Español

    Ojo: Java y JavaScript son lenguajes distintos, aunque se parezcan en el nombre.

Por tu lado: electrónica y robots

Medio

Para: conectar el código con el mundo real: luces, sensores, robots.

Lo que vimos en el taller. Puedes practicar sin comprar nada con un simulador en línea.

▶ Curso de Arduino desde cero · 45 videosSimular Arduino (Tinkercad)

Lenguajes avanzados

Cuando ya manejes bien la lógica y JavaScript, estos son los siguientes pasos. Mi recomendación de orden: Java primero y Python después.

Java

Avanzado

Para: aplicaciones, sistemas grandes y apps para Android.

Es estricto y ordenado: te obliga a declarar bien tus datos y a organizar el código. Eso te forma buenos hábitos desde el principio.

▶ Curso de Java desde cero · MoureDev, unas 8 h 50 min

C++

Avanzado

Para: videojuegos, programas muy rápidos y electrónica.

Es la base de lo que escribes en Arduino. Te enseña cómo trabaja la computadora por dentro, y por eso es más exigente.

▶ Curso de C++ desde cero · Sinergia, unas 9 h 30 min

Python

Después de Java

Muy popular para ciencia de datos, automatización e inteligencia artificial. Su sintaxis es sencilla, y por eso conviene aprenderlo con una base sólida: si empiezas por aquí, es fácil adquirir hábitos que luego cuestan trabajo en lenguajes más estrictos como Java.

▶ Curso de Python · MoureDev, más de 10 h

Tres consejos finales

  • Equivocarte es parte del proceso. Todos los programadores ven errores todos los días.
  • Haz proyectos pequeños. Terminar algo chico enseña más que empezar algo gigante.
  • Practica fuera de clase. Lo que haces por tu cuenta es lo que más te hace avanzar.
